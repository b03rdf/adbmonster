# ADB Monster (adb缝合怪)

一站式 Android 调试桌面工具。整合 adb 常用功能：设备管理、实时 logcat、截图录屏、APK 管理、scrcpy 投屏等。

## 功能

- **设备管理** — USB/无线连接、QR 码配对、设备列表自动刷新
- **自动连接** — USB设备自动选中；无可用设备时检测并连接本地模拟器，默认 `127.0.0.1:7555`
- **实时 Logcat** — 虚拟滚动渲染、级别/文本过滤、搜索跳转、自动滚屏、标签配色
- **截图 & 录屏** — 一键截图保存、录屏录制并拉取到本地
- **APK 管理** — 安装/卸载、清除数据、查看包信息、提取 APK
- **CLog 导出** — 从设备拉取指定应用的 CLog 目录
- **Scrcpy 投屏** — 一键启动/停止 scrcpy 实时屏幕投影
- **系统托盘** — 关闭窗口最小化到托盘，后台运行
- **设备实时仪表盘** — 查看 CPU、内存、存储、电量、温度、运行时间和前台 Activity
- **一键诊断包** — 导出设备信息、日志、截图、应用性能数据和可选完整 Bugreport ZIP
- **增强 Logcat** — 多缓冲区、正则过滤、崩溃/ANR 统计、暂停缓存和筛选结果导出
- **手游弱网测试** — 通过免 Root 的 VPN 助手对指定应用模拟上下行带宽、延迟、抖动和 UDP 包异常，支持预设与定时恢复
- **统一任务中心** — 管理日志、录屏/保存、投屏、诊断和弱网任务，支持停止、设备筛选、清理结果与本地历史恢复

## 使用说明

- 无线连接前，需要在 Android 设备上开启开发者选项和无线调试；不同 Android 版本的配对端口与连接端口可能不同。
- 自动连接默认开启并优先使用USB设备；可通过设备选择器右侧的设置按钮修改本地模拟器端口或关闭自动连接。
- 单次录屏使用 Android `screenrecord`，最长 180 秒。
- 关闭主窗口后程序会最小化到系统托盘；请从托盘菜单选择“退出”以完全结束程序。
- 删除远程文件前会二次确认，后端同时拒绝删除 `/`、`/sdcard`、`/storage` 和 `/data` 等保护路径。

### 任务中心与异常恢复

- 点击顶部“任务”查看所有设备的长任务。任务绑定启动时的设备；切换设备不会把已有任务转移到新设备。日志面板切换设备时会停止原日志采集。
- “停止”先进入清理状态，清理完成后记录最终结果。录屏停止后仍保留设备文件，请到“多媒体”保存；如果设备无法重连，可以选择“保留设备文件并释放录屏占用”，再开始新录屏。
- 后端每 3 秒检查活动任务的设备连接，连续两次检查不可用时请求停止。ADB 查询自身有 5 秒超时，断连检测并非即时完成。
- 诊断总时限 600 秒、录屏保存 120 秒、弱网启动 90 秒；日志和投屏持续运行至停止或进程结束。录屏有设备端 180 秒上限及桌面端 190 秒兜底。
- 从托盘退出或正常退出时，程序统一停止活动任务，最多等待 25 秒。未确认的设备恢复不会显示为成功；强制结束程序或断电不能保证执行清理。
- 最近 200 条已结束任务的元数据保存在应用本地数据目录的 `task-history.json`。重启后，未正常结束的旧任务标记为“异常中断”，不会自动重放。历史包含设备标识、包名、路径和错误信息，请注意分享范围。
- 清除任务历史不会删除实际文件。诊断与录屏保存使用临时文件，完成后才发布到用户选择的目标路径。

实现与验收说明见 [任务管理说明](docs/task-management.md)，后续方向见 [发展路线](docs/ROADMAP.md)。

### 弱网测试

1. 连接 Android 7.0（API 24）或更高版本的设备，进入右侧“工具”标签页。
2. 首次使用时点击“安装 VPN 弱网助手”，再点击“在设备上授权 VPN”并接受系统弹窗；不需要 Root。
3. 输入或从候选项中选择要测试的应用包名，然后选择“轻度弱网”“3G 网络”“极差网络”或自定义参数。
4. 点击“应用弱网”开始测试。只有目标应用流量会进入 VPN，ADB 和设备上的其他应用不受影响。
5. 倒计时结束后桌面端会关闭 VPN；也可以随时点击“停止并恢复”。桌面端退出时也会清理代理和 `adb reverse` 映射；设备端另有总时长 +90 秒的紧急恢复兜底。
6. 进入“场景配置与效果观测”可保存/载入配置，执行正常 → 高延迟 → 短时断网 → 恢复等多阶段场景，查看实测吞吐、连接、队列及分原因丢弃，并导出 JSON 报告。详见[配置、指标口径与验收清单](docs/weak-network-scenarios.md)。

实现上，辅助 APK 使用 Android `VpnService` 和 HEV Socks5 Tunnel，把目标应用的 TCP/UDP 流量经 `adb reverse` 转发给桌面端的临时鉴权 SOCKS5 代理。桌面端不解密 HTTPS 等应用层内容。

- 上下行带宽、基础延迟和抖动对 TCP、UDP 均生效。每个方向的带宽为目标应用所有 TCP/UDP 连接合计值；0 表示不限速，首个数据块也计入带宽。
- UDP 待发送队列在整个会话内最多容纳 256 个数据报，队列满时丢弃新到数据报，因此持续过载时实际丢包可能高于设置值。
- 丢包、重复包和乱序只对 UDP 数据报生效；对可靠 TCP 字节流人为删除或复制字节会破坏连接，因此不做伪实现。
- Android 同时只能启用一个 VPN；开始测试前应先关闭设备上的其他 VPN，停止助手后原 VPN 不会自动重连。
- 单次测试时长限制为 10～3600 秒。若桌面端意外退出，设备端到期计时仍会关闭 VPN。
- 辅助 APK 源码、第三方许可证和构建说明位于 [`vpn-helper`](vpn-helper/README.md)。桌面端内嵌的安装包位于 `src-tauri/resources/adb-monster-vpn-helper.apk`。

助手 1.0.3 修复停止后 VPN 网卡仍被系统绑定的问题：手动停止和到期恢复会主动关闭隧道、释放网卡及路由，桌面端也会核对实际网卡状态。保留 1.0.2 的紧急恢复缓冲及此前的兼容性修复。旧版本请在面板点击“更新 VPN 弱网助手”。
