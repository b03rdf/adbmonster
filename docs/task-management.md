# 统一任务管理

## 当前范围

统一管理 Logcat、screenrecord 录屏及其保存、scrcpy 投屏、诊断导出、VPN 弱网。
设备列表和性能轮询等查询不会产生任务历史。APK 安装、普通文件传输及其他短操作暂未接入任务中心。
当前保留每种任务一个活动实例的限制；这不是多设备并行执行器。不同种类可以并行，且归属设备互不影响。

## 结构与接口

- `src-tauri/src/tasks.rs`：设备绑定的任务 ID、状态转换、取消信号、进程监督、断连检测、历史和退出处理。
- `commands/*`：模块自己的业务资源和清理策略。使用 `Task::run` 执行可取消/有总时限的异步操作，资源清理结束后才写入终态。
- `TaskGuard`：受监督任务异常退出时记录“异常中断”，不伪报已完成清理。
- `list_tasks` 返回带 `revision` 的全量快照；`tasks:changed` 推送相同格式。前端拒绝旧版本快照，并用 2 秒轮询补偿事件缺失。
- `cancel_task(taskId)` 只向指定任务发送停止请求，不根据当前选中设备或任务种类去停止新的任务。重复停止是幂等的。
- `clear_task_history` 仅清除已结束的元数据，运行/清理中的任务不能被清除，不删除实际产物。

状态从启动中进入运行中；取消请求进入停止/清理中；终态是完成、已停止、失败或异常中断。
迟到的进度和完成通知不能复活终态任务。历史不存储 Logcat 内容、弱网认证参数或命令参数全集，但错误信息和文件路径仍可能敏感。

## 清理语义

| 任务 | 停止/异常处理 | 数据保护 |
|---|---|---|
| Logcat / scrcpy | 监督实际子进程退出；有界排空输出并回收流读取任务 | 限制输出缓存；普通 scrcpy stderr 不自动当成错误 |
| 录屏 | 校验专属 PID 对应的唯一文件路径后发送 SIGINT，失败则停止本地 ADB 并报告设备状态未确认 | 停止不删除设备文件；可保存或仅释放占用 |
| 录屏保存 | 120 秒时限，拉取可取消，提交阶段不再中断 | 先写临时文件，成功发布后才尝试删除已确认结束的设备录屏 |
| 诊断 | 采集可取消；ZIP 工作线程在数据块之间检查取消/总时限，等待线程结束后清理 | 不让后台压缩与临时目录清理竞争；失败/取消不发布半成品 |
| 弱网 | 先停止本地代理，再清理 VPN 与反向映射；停止后查询助手状态 | 失败保留恢复提示；设备端到期关闭作为断连兜底 |

正常退出统一进入关停状态，不再接受新任务。25 秒仍未结束的任务记录为清理超时/异常中断。
强制杀进程、系统断电、设备离线时无法保证远程清理。重新连接后应检查任务历史和 VPN 助手，必要时使用弱网面板重新检测并停止残留 VPN。

录屏 SIGINT 退出依据 Android 的 screenrecord 信号处理实现：
[AOSP screenrecord](https://android.googlesource.com/platform/frameworks/av/+/refs/heads/android11-mainline-extservices-release/cmds/screenrecord/screenrecord.cpp)。
不同厂商的 `/proc` 可见性和命令行为仍需要实机验证；无法验证时保留文件，不声称安全删除。

## 自动化验证

`npm run check` 覆盖前端构建、任务/弱网状态测试、Rust 格式、Clippy 和 Rust 测试。
更严格的测试代码检查：`cargo clippy --manifest-path src-tauri/Cargo.toml --all-targets -- -D warnings`。

任务回归覆盖：旧 ID 不影响新任务、重复取消、迟到状态、取消前置检查、阻塞写取消、总超时释放资源、取消监听结束、历史上限和原子覆盖、异常重启标记、ZIP 中途取消保护已有报告。

## 实机验收清单（尚未完成全量验收）

1. 分别启动五类长任务，核对任务 ID、设备、目标应用（适用时）、时间、进度和最终结果。
2. 在 A 设备启动任务后切换到 B；从任务中心停止 A，确认不操作 B。
3. 连续点击启动/停止，确认旧任务停止通知不影响新任务，同类任务不会重叠占用资源。
4. 录屏 10 秒后停止并保存，确认 MP4 可播放；模拟拉取失败后可重试，释放占用不会删文件。
5. 在诊断采集和大文件压缩阶段分别取消；原有同名报告不受影响，临时目录清理结果可见。
6. 拔线、重启 ADB、取消设备授权，确认本地任务停止，设备端清理未确认时有明确提示。
7. 弱网手动停止与到期恢复均更新任务中心；设备离线时不得显示 VPN 已确认恢复。
8. 多任务运行时从托盘退出，再次启动检查历史。强制结束程序后重启，旧活动任务显示异常中断且不自动重放。
9. 使用无写入权限的导出位置/任务历史位置，确认错误可见，设备文件和旧报告保留。
10. 验证屏幕关闭、长时间静止画面以及厂商后台限制下的录屏停止行为。
